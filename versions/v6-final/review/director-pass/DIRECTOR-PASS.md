## Четыре точечных изменения

- **S03:** initial state — прежние headline / short lead, крупный lipoprotein cutaway, подпись оболочки и оговорка о концептуальном разрезе. Cargo / TG и ApoB скрыты до выбора соответствующего состояния. В каждом состоянии виден свой слой; скрытые элементы убраны также из accessibility tree. Изображение остаётся разрезом LDL, его нельзя принимать за HDL. ApoB — показатель числа атерогенных частиц, не только LDL.
- **S02:** та же композиция и героиня. Контекстные подписи без карточек и заметных рамок, с последовательным раскрытием: питание → наследственность → активность → давление / обмен → сон / стресс → медицинский контекст. В static / reduced motion доступны все подписи.
- **S09 / S13:** сохранены упаковка, notebook и интерактивная логика. Controls стали спокойнее: прозрачный фон, тонкое подчёркивание выбранного состояния. Поворот упаковки, четыре label states, три привычки и 14 отметок работают. На 320 px дни расположены в пять колонок, чтобы зоны нажатия оставались не меньше 44 px.
- **Mobile:** устранён letterboxing S03 / S06 / S14; headline, hero и interaction ближе друг к другу. В S12 исправлено наложение, скрывавшее лица. S13 имеет высоту по содержимому вместо пустого растяжения на экран. Отключён scroll anchoring внутри истории: смена текста в S03 / S09 / S13 не сдвигает кадр и не прячет headline за header.
