# QA · Codex V2 · 02.10.2026

## Результат

7 размеров от 320 до 1920 px, 14 исходных глав, без горизонтального переполнения. 16 проверок взаимодействий прошли. Ошибок JavaScript нет. Полные данные находятся в `qa-results-v2.json`.

На всех размерах проверены фактическое воспроизведение MP4 и положительное время проигрывания первого экрана, а также воспроизведение видеокарточки. В шоуриле проверены длительность ровно 28 секунд, воспроизведение из header, hero и большой карточки, закрытие с немедленной остановкой. При системном уменьшении движения и общем выключателе все видео остановлены. Проверены исходные замены продуктов, этикетка, факторы риска, выбор привычки, меню и Escape, якорь s04, чтение без JavaScript.

## Визуальная проверка

Проверены рендеры главного экрана и шоурила на 390 и 1440 px. Исправлено кадрирование: desktop видео зеркально расположено справа от текста, мобильная версия использует самостоятельный crop. Крупный план еды кадрирован без дополнительного героя. Титры шоурила проверены на контактном листе. Все ролики H.264 / yuv420p с faststart; исходная съёмка Full HD.

## Предел проверки

Chromium 153 / Playwright, эмуляция размеров. Safari на физическом iPhone/iPad не проверялся. При запрете autoplay остаётся постер, шоурил запускается по нажатию. Звука в ролике нет. Медицинские тезисы сохранены из V1, согласование врачом остаётся незавершённым. Движение в медицинском фрагменте является условной визуализацией из собственного VERBA Heart, не данными пациента.
