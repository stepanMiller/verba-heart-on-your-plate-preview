# VERBA V4 · Master direction · 04.10.2026

## Creative concept

Не список полезных продуктов, а визуальное путешествие от тарелки к липидному профилю: что мы меняем в еде, что меняется в организме и почему итог зависит от человека целиком.

Один экран — один тезис и один ведущий объект. Молочный фон, спокойный зелёный, графит, редкий янтарный акцент; крупная редакционная типографика. Еда, прозрачные научные схемы и собственный сосудистый CGI говорят на одном языке. Схемы показывают направление и механизм, никогда величину индивидуального эффекта. В каждом научном экране источник доступен по «Подробнее»; первый слой тоже содержит причинность.

## Motion / showreel / production

Новый 24-секундный H.264 showreel, без звука: title/food → lipoprotein → pouring oil → soluble fibre → sugar/TG → label turn → vascular CGI → close. Единая палитра и типографика; короткие титры. Новые научные кадры берутся из реально работающей V4-сцены, а не сторонних AI-картинок. Процедурное движение достаточно: платных генераций 0, новых AI stills 0, Runway не нужен, credits 0.

Canvas, CSS и видео останавливаются вне экрана, в скрытой вкладке и при открытом диалоге. Reduced motion и Save-Data стартуют со статичными схемами / posters, видео не получает src. Без JS читаются все тезисы, видны SVG fallback и доступны details/источники. Нет wheel hijacking, внешних шрифтов, runtime CDN, аналитики и отправки выбора привычки.
