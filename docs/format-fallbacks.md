# Замены и резервные состояния

| Web-поведение | Резервное состояние |
|---|---|
| Фоновый MP4 | Статичный постер при reduced motion, при Save-Data или отказе autoplay |
| Закреплённая сфера и тарелка | Обычные блоки на телефоне; все тексты присутствуют в документе |
| Canvas / эффекты появления | Статичное поле частиц и сразу видимый текст при reduced motion |
| Фильм | Полноценный MP4 с нативными controls; автозапуск может требовать нажатия Play |
| JavaScript отключён | Вся история и раскрываемые пояснения доступны, интерактивные варианты не переключаются |
| Печать из браузера | Убрана фиксированная навигация, видео заменено постером; это резерв чтения, а не отдельная свёрстанная PDF-презентация |

PPTX и Google Slides в этом запросе не создавались; анимации не заявляются переносимыми в эти форматы.
