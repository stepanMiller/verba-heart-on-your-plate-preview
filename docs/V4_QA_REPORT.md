- Три клинических контекста без риск-скоринга; три вопроса врачу; три варианта одной привычки.
- Содержание: 14 ссылок, переход к сцене и правильный счётчик. Скролл браузера сохраняется; перехвата wheel / touch / keyboard нет.
- Воспроизведение ambient oil / food / vascular CGI; остановка за экраном, в диалоге, по общей паузе и по событию скрытой вкладки. Hidden-document lifecycle проверен симуляцией свойства + `visibilitychange`.
- Reduced motion: статичный первый просмотр, видео без `src` и без MP4-запросов. Save-Data: тот же принцип. Ручное воспроизведение showreel доступно по явному запросу.
- Autoplay rejection: poster остаётся виден. Без JS: читаются 14 сцен и раскрываются native details с источниками.
- Новый showreel загружается, имеет длительность **24s**, воспроизводится и останавливается при закрытии в обоих движках. Фокус возвращается к кнопке запуска.

WebKit в этом Linux-окружении потребовал недостающие библиотеки из Debian, загруженные / распакованные в `/workspace`, и право создавать временные медиафайлы в `/var/tmp`. Системные пакеты не изменены. Первоначальная неудача видеопроверки была связана с временным файлом, затем тест успешно повторён. Это не физический Safari / iOS.
