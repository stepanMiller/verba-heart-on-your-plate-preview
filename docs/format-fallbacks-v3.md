# Поведение и статические замены V3

| Поведение | Замена / ограничение | Проверка |
|---|---|---|
| Нативные hero-сцены | Минимум 100svh; на очень узком/невысоком экране и при увеличении текста высота растёт. Нет внутреннего скролла или захвата wheel/touch | 8 размеров, нативное колесо и якоря |
| Реальные MP4-фоны | Локальный WebP-постер при запрете autoplay, Save-Data и reduced motion | Постеры доступны; reduced motion останавливает воспроизведение |
| Canvas-частица | CSS-сфера без JavaScript или при недоступности Canvas; условная иллюстрация, не измерение | No-JS и системная пауза |
| Dolly, вход текста, дыхание схемы | Неподвижная читаемая композиция при reduced motion и manual pause | Проверено |
| Переключатели | Начальное состояние остаётся видимым без JavaScript; полные альтернативы и ограничения есть в приложении | Проверено чтение и раскрытие заметок без JS |
| Модальные пояснения | Те же тексты доступны в нижнем нативном details-приложении | Escape, фокус, no-JS |
| Шоурил | Только по запросу; controls, 28 секунд, без звука. Требуется JS для открытия модального проигрывателя | Открытие, воспроизведение и немедленная остановка при закрытии |
| PDF / PPTX | Не создавались. Print CSS — только вспомогательное статичное чтение, не обещание проверенного PDF/PPTX-экспорта | Не тестировалось |

Активные ассеты локальные, внешних JS-зависимостей и шрифтов нет. Выбор привычки не сохраняется между перезагрузками и не передаётся на сервер.
