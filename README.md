# Сердце на вашей тарелке · VERBA

Автор версии: **Codex, V3**. Ветка сравнения: **codex/v3-hero-scenes-2026-10-03**.

14 коротких hero-сцен вместо длинной статьи. На каждом экране один тезис, одно короткое пояснение и один ведущий визуал: предметная фотография, частица, видео, этикетка или крупный вопрос. Большие светлые поля и нативная прокрутка. Исходные якоря s01–s14 сохранены; лишний блок между первым и вторым экранами удалён.

## Просмотр

Статический сайт без сборки и сторонних JS-зависимостей. Откройте index.html или запустите python -m http.server 4173 в корне репозитория. Все активные ассеты локальные. Главная ветка, GitHub Pages и версии других агентов не меняются.

При просмотре через raw.githack используйте точный SHA коммита, а не mutable-ветку. Относительные ассеты загрузятся из того же коммита. Ссылки на просмотр и PR находятся в сообщении агента.

## Редактирование

- index.html: текст, порядок сцен, приложение и источники.
- scenes.css: визуальные роли, экранные композиции, адаптивность, движение и статические замены V3.
- scenes.js: нативный скролл, Canvas, переключатели, модальные пояснения, видео и локальный выбор привычки.
- styles.css, app.js, cinema.css и cinema.js: архивный код V1/V2, в V3 не подключается.
- assets/: оптимизированные WebP и MP4.
- docs/: Blueprint, Style Brief, направление V3, источники, manifest, QA и рендеры.

Пояснения открываются по запросу; без JavaScript доступны в приложении внизу. Никаких прокручиваемых статей внутри сцены, захвата wheel/touch или принудительной фиксации страниц. Системное уменьшение движения и общий переключатель поддерживаются. При reduced motion, Save-Data или отказе autoplay остаётся постер. Canvas и фоновые видео останавливаются вне видимой области.

Шоурил V2 сохранён: 28 секунд, без звука, настоящая съёмка еды и условная визуализация из собственного VERBA Heart. Открывается на первом экране, из верхней навигации и в s08. В s08 движется крупный план приготовления салата; в s11 — шестисекундный сосудистый фрагмент собственного референса. У фильма есть обычные controls; при закрытии он сразу останавливается. Выбор привычки остаётся только в оперативной памяти; аналитики, форм персональных данных и отправки выбора нет.

Материал просветительский, медицинское согласование не завершено. Люди в стоковом видео не обозначаются как пациенты или сотрудники VERBA. Учебные фотографии созданы ИИ; их персонажи вымышлены. Источники и prompt находятся в docs/sources.md.
