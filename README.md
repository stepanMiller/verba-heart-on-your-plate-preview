## Просмотр и редактирование

Статическая страница без сторонних JavaScript-библиотек, аналитики и форм отправки данных. `npm run dev` запускает локальный сервер, `npm run check` проверяет синтаксис JavaScript. Для GitHub Pages файлы готовы к публикации из корня выбранной ветки. Все пути относительные, поэтому страница работает в каталоге репозитория.

Обычная прокрутка доступна без JavaScript. Вспомогательные пояснения раскрываются через нативные `details`. Переключатель «Пауза» останавливает видео и анимации. При `prefers-reduced-motion` движение отключено, при экономии трафика видео изначально не загружаются. Если автоматическое воспроизведение запрещено браузером, остаются обложки.

Шрифты и оптимизированные иллюстрации хранятся в `assets/`. Исходные иллюстрации черновика сохранены. Два коротких видеофрагмента взяты из существующих фильмов MILLER, звук и прежние подписи удалены. Новых платных генераций не запускалось. Учебные персонажи вымышлены; внешность не используется для оценки медицинского риска.
