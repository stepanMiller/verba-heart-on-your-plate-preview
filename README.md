# Сердце на вашей тарелке · VERBA · Codex, версия 3

[Открыть страницу](https://verba-scroll-film-20261002.spartak19876.chatgpt.site) · [Ветка GitHub](https://github.com/stepanMiller/verba-heart-on-your-plate-preview/tree/codex/verba-scroll-film-20261002)

Лекция о питании: продукты на тарелке, простые замены, привычный рацион, этикетка и один первый шаг. Шесть глав доступны обычным вертикальным скроллом. Первый экран использует фотографию еды из исходного черновика. Видео показывает продукты крупным планом и приготовление: нарезку овощей и масло на салате.

Статические HTML, CSS и JavaScript. `npm run dev` запускает локальный сервер, `npm run check` проверяет синтаксис. Для GitHub Pages файлы готовы к публикации из корня выбранной ветки; пути относительные.

Чтение не требует JavaScript. Весь основной материал виден без раскрытия вкладок. Кнопка «Пауза» останавливает движение. При reduced motion и экономии трафика видео изначально не загружается. При ограничении autoplay остаётся обложка. Выбор привычки никуда не отправляется.

Ветка `codex/verba-scroll-film-20261002` предназначена для сравнения вариантов. В `main` версия не вливается. Первое издание сохранено в истории коммитов.
