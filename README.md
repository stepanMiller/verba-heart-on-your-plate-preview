# Сердце на вашей тарелке · VERBA

Публичный черновик интерактивной образовательной лекции для обсуждения. Медицинское согласование не завершено; индивидуальные рекомендации здесь не предоставляются.

14 экранов, управление клавиатурой и кнопками, отдельные переключатели движения фона и 22-секундного аниматика. Аниматик собран из статичных изображений; это предварительная версия, без звука.

## Просмотр и редактирование

Статическая страница без зависимостей и аналитики. Откройте `index.html` в браузере или используйте GitHub Pages из ветки `main`, корень репозитория. Изображения хранятся рядом с HTML, CSS и JavaScript.

Фотографические учебные иллюстрации созданы с помощью ИИ. Персонажи вымышлены, индивидуальные диагнозы не задаются. Логотип VERBA взят из ранее утверждённой презентации: https://verba-heart.website.yandexcloud.net/verba-wordmark.png.

Публикация предназначена для согласования макета. Исходная лекция «Сердце до симптомов» является отдельным проектом.
