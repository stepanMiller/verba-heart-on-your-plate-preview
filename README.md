# Сердце на вашей тарелке · VERBA

Автор версии: **Codex, V1**. Ветка сравнения: **`codex/scroll-story-2026-10-02`**.

Полная переработка 14-экранного черновика в непрерывную web-историю. Главный экран с людьми, анимированный фотофон, визуальный липидный профиль, закреплённая тарелка, интерактивные замены, этикетка и выбор одной привычки. Естественная прокрутка мышью и пальцем, все якоря `s01`–`s14` сохранены.

## Просмотр

Это статический сайт без сборки и сторонних JS-зависимостей. Откройте `index.html` или запустите `python -m http.server 4173` в корне репозитория. Все ассеты локальные. Основная GitHub Pages-версия и ветки других агентов не меняются.

При просмотре ветки через raw.githack следует использовать точный SHA коммита для HTML и относительных ассетов. Ссылки на просмотр и PR будут в финальном сообщении агента.

## Редактирование

- `index.html`: текст, порядок глав, подписи, вопросы и источники.
- `styles.css`: визуальные токены, типографика, адаптивность и движение.
- `app.js`: скролл-состояния, Canvas, меню, табы, фильм и выбор привычки.
- `assets/`: оптимизированные WebP и MP4.
- `docs/`: Blueprint, Style Brief, источники, manifest, QA и рендеры.

Системное уменьшение движения и общий переключатель поддерживаются. На телефоне видеофон автоматически не загружается; изображения анимируются CSS. Canvas и фоновые видео останавливаются вне видимой области. Фильм является анимацией фотографий, без звука. Выбор привычки остаётся только в оперативной памяти страницы; аналитики, форм сбора персональных данных и отправки выбора нет.

Материал просветительский и остаётся дизайн-версией для обсуждения; медицинское согласование не завершено. Фото созданы ИИ, люди вымышлены и не обозначаются как пациенты или сотрудники VERBA. Источники и prompt находятся в `docs/sources.md`.
